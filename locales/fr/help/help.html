Activation
Cochez cette case pour mettre la partie publique du blog en mode construction. Les visiteurs voient alors le message à la place du blog. L'administration n'est pas touchée.
IP autorisées
Une adresse IP par ligne. Ces visiteurs voient le blog normalement. Ajoutez votre propre adresse IP, indiquée sous le champ, pour vérifier votre blog pendant la construction.
Autres types d'URL autorisées
Types de pages publiques qui restent accessibles à tous, séparés par des virgules, par exemple feed pour garder les flux de syndication. La page de contact reste toujours accessible.
Titre
Titre de la page de construction.
Message
Texte de la page de construction, en HTML.
